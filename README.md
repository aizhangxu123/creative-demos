# creative-demos

创意网页与交互效果作品集。

- 首页：https://aizhangxu123.github.io/creative-demos/
- Lucy 闪卡：https://aizhangxu123.github.io/creative-demos/lucy-card/

## 发布

在 Settings → Pages 中选择 Deploy from a branch，分支 main，目录 / (root)，保存。

## 添加作品

每个 Demo 使用独立文件夹，包含 index.html 和相关资源，然后在首页添加入口。

Lucy Demo 使用 HTML/CSS/JavaScript 实现卡片透视、镭射光效与图片/文字视差，不包含 Blender 工程，也不是原版 holo-card-studio 完整流水线产物。主题图片为 AI 生成的非官方《赛博朋克：边缘行者》同人图；角色与相关作品权利归各自权利人所有。
